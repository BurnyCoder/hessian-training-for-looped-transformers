# Repository conventions

- Install the locked environment with `uv sync --frozen`. The usual `uv run pytest` includes tests that execute models.
- For a model-free audit use `uv run pytest -q tests/test_stats.py tests/test_audit_reporting.py` and `uv run python main.py report`. The report reads stored records, regenerates input sets and renders the paper. Frozen evidence and its byte manifest live in `results/audit-2026-11-26/`.
- Empirical numbers in current publications come from report blocks, archived measurements or cited primary sources. Protocol constants belong in the resolved configuration or preregistration. Add new amendments at the bottom of `reports/preregistration.md` before the outcomes they can affect; disclose previous exposure.
- Interpret a single training pair descriptively. Preserve run name, completion status, training seed/settings, evaluation streams and order, counts, and uncertainty type. Exact match includes EOS. The registered primary is the equal-length mean of per-length oracles.
- Use `third_order_safe()` for the network penalty graph. The [operator record](results/audit-2026-11-26/layernorm_operator.json) identifies the affected build, dtype and CPU fixture. The original memory cap and chunk-size choices are machine-specific; see [benchmarks](results/benchmark/) and [the audit](reports/reviews/2026-11-26-scientific-audit.md).
- For a separately authorized experiment, see the [README](README.md) for individual phases. Smoke runs write to `results/smoke/`, which is ignored. The live raw JSON/logs are under `results/`; local weights are under the ignored `checkpoints/`. Hugging Face publishing requires a completed evaluated checkpoint and explicit credentials through the normal Hub configuration.
